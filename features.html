FEATURES

听见，也看见。

把搜索、播放与可视化收进同一个播放器。下面是 Mineradio 的核心能力说明。

免费下载 查看历史版本 和其他播放器对比

01 · SEARCH

聚合搜索

统一搜索网易云、QQ 音乐、酷狗、Spotify 等音源，少切几个 App。结果列表干净，点开就能播。

02 · VISUAL

封面粒子可视化

专辑封面拆成粒子，随节拍与氛围律动。听歌时视线有落点，把播放器做成视觉舞台，而不只是歌单工具。

03 · LIBRARY

3D 歌单架

立体化浏览与管理歌单，减少「列表堆砌」的工具感。适合喜欢界面沉浸、愿意多停留一会儿的听歌用户。

04 · LYRICS

桌面歌词与手势

悬浮桌面歌词，配合手势控制切歌与播放。工作、摸鱼听歌时不必反复切回主窗口。

05 · SCENE

流体城市音域

随音乐起伏的科幻场景氛围，和粒子、歌单架同一视觉语言。想盯着画面听歌时更有「在场感」。

06 · PLATFORMS

四端可用

Windows、macOS、Android 与网页版（mineradio.art）。想先试听可开网页版；要沉浸桌面体验再装客户端。

07 · OPEN

免费开源

GPL-3.0，无广告、无内购。安装包请从 mineradio.cn 官方网盘获取；源码见 GitHub。

08 · WEB

网页版 Bridge

浏览器打开即可用。首次访问需安装 Bridge 扩展以接通音源（Chrome / Edge）。适合临时听歌与跨设备试用。
