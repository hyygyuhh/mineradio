Install guide

四端安装与排错

先下载正式包，再按系统处理拦截提示

请只使用 官方下载页 公布的网盘链接。项目持续更新中，请下载最新版本。

Windows

v2.2.0 · Setup.exe

● 为你的设备推荐
  1. 从下载页获取 Mineradio-2.2.0-Setup.exe。
  2. 双击安装，按提示完成。
  3. 浏览器拦截：下载栏「…」→「保留 / 仍要保留」。
  4. SmartScreen：点「更多信息」→「仍要运行」。
  5. 杀毒明确报木马并隔离：删文件后换源重下。
去下载 Windows 版 →

macOS

v2.2.0 · DMG · Apple / Intel

● 为你的设备推荐
  1. 打开 DMG，把 Mineradio 拖进「应用程序」。
  2. 若提示「已损坏」，打开终端执行：
xattr -cr /Applications/Mineradio.app
  1. 密码输入时终端不回显，属正常。
  2. 仍打不开：系统设置 → 隐私与安全性 → 仍要打开。
  3. Apple / Intel 已合并为一包；可用 Rosetta 运行。
去下载 macOS 版 →

Android

v2.1.0 · APK

● 为你的设备推荐
  1. 下载 Mineradio_2.1.0.apk。
  2. 允许「未知来源 / 安装未知应用」。
  3. 若变成 .apk.1，重命名回 .apk 再装。
去下载 Android 版 →

网页版

mineradio.art · 免安装

● 为你的设备推荐
  1. 浏览器打开 mineradio.art。
  2. 首次按提示安装 Bridge 扩展（Chrome / Edge）。
  3. 登录账号即可使用。暂无独立 iOS App。

只用 mineradio.cn 公布的网盘或 GitHub / Gitee 正式附件，勿装「破解版 / 绿色版」。

拦截很常见
